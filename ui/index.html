    Spider Donut Help

    Spider Donut Installer

    Build the PS3 runner and prepare your own DELTARUNE chapters for a USB drive.

    Before you begin

    You need a Windows 10/11 x64 PC, an internet connection, at least 8 GB free for build tools, and enough additional space for your chapters and finished ZIP. The app prepares a separate Ubuntu build environment using Windows Subsystem for Linux. Windows may ask for administrator access and a restart on first use.

    Your game folder

    Choose the DELTARUNE folder containing chapter1_windows, chapter2_windows, and so on. You can also choose an individual chapter folder. Each selected chapter gets its own PS3 TEXTURES.BIN. Your original files stay in place.

    Developer access

    Choose Dev Beta, open the encrypted .spiderkey file supplied by the owner, then enter its password. Keys are checked locally and can expire. Keep the file and password safe.

    Putting the build on your PS3

    Extract the finished ZIP to the root of a FAT32 USB drive. Keep the PKG and DELTARUNE folder at the root. Install the PKG through Package Manager on your HEN/CFW PS3, then launch Spider Donut and choose a chapter.

    If a build stops

    Open View → Show Build Log for the compiler output. You can go back and retry. Completed downloads are cached. Cancelling a build never changes your original game files.

    Developer Keys

    Create a Developer Key

    Save an encrypted, signed file for your developer.

    Give the developer this password separately from the file. Use a different password for each developer.

    Your signing key is encrypted for your Windows account. Keep an encrypted owner backup so you can recover it after reinstalling Windows.

    Owner Signing-Key Backup

    Export an Encrypted Backup

    This backup lets you restore your signing identity on another Windows installation. Keep it private.

    Use a separate password that you never give to developers. The backup cannot be recovered without its password.
